[导航]
Alt+左 / Alt+右 以及鼠标侧键：
    在多条已选动画的历史记录里前后跳转，和网页浏览器一样。
上 / 下：
    选择上一条 / 下一条动画。
    按住 Shift 可一次跳过若干条动画。
    按住 Ctrl 则在各个 TAE 之间跳转，而不是动画。
Page Up / Page Down：
    在上一 / 下一个 TAE 中选择相同的子 ID（例如从 a25_4000 跳到 a26_4000）


[播放]
空格键：
    播放 / 暂停动画。
Ctrl+R：
    重置动画 / 根运动 / 声音（执行「硬重置」）。
Shift+空格键：
    重置动画 / 根运动 / 声音（执行「硬重置」），并立即从头开始播放动画。
Ctrl+空格键：
    重新选中当前动画；若在「模拟」标签页里启用了混合，则应用混合过渡。
左 / 右方向键：
    跳到上一帧 / 下一帧。
Home / End：
    跳到动画开头 / 动画结尾。


[图形编辑器]
在时间轴上左键拖拽：
    拖动动画帧。
在时间轴上左键 + Shift + 拖拽：
    拖动动画帧，同时忽略自动滚动。
在所选动作中部左键拖拽：
    整体移动动作。
在所选动作左 / 右边缘左键拖拽：
    移动动作的开始 / 结束时间。
左键单击：
    选中鼠标下方的动作。
左键拖动：
    拉出选择框，高亮多个动作。
Shift + 左键：
    加入当前选择（对拖动多选同样有效）。
Ctrl + 左键：
    从当前选择中减去（对拖动多选同样有效）。
Ctrl + 右键：
    在鼠标位置新建一个动作。默认类型与该轨道上的第一个动作相同（最好让同一条轨道上只放同类型的动作）。
Delete：
    删除高亮的动作。
Ctrl+A：
    选中图形里的全部动作。
Ctrl+X / Ctrl+C / Ctrl+V：
    剪切 / 复制 / 粘贴。
Ctrl+F：
    打开「查找数值」对话框。
Ctrl+G：
    打开「跳转到动画 ID」对话框。
Ctrl+H：
    打开「跳转到 TAE ID」对话框。
Ctrl+I：
    打开「从动画 ID 导入」对话框。
F1：
    更改高亮动作的类型（仅在只选中 1 个时可用）。
F2：
    更改当前动画的名称。
Shift+F2：
    更改当前 TAE 的名称。
F3：
    打开动画属性编辑器。
Shift+F3：
    打开 TAE 属性编辑器。
F4：
    跳转到被引用的动画（适用于引用其他动画的动画）。
F5：
    强制游戏内热重载（在支持的情况下）。
F6：
    重新排序轨道并重生成轨道名。
    按住 Shift 可对所有动画执行。
Ctrl+鼠标滚轮（在图形中）：
    放大 / 缩小时间轴。
Ctrl+(+/-/0)：
    放大 / 缩小 / 重置缩放。
Insert：
    把当前动画复制成新条目。
    按住 Shift 则改为把当前 TAE 复制成新的 TAE 文件。


[视口]
鼠标滚轮（在视口中）：
    放大 / 缩小。
    Shift 加快。
    Ctrl 放慢。
右键拖拽：
    上下左右移动摄像机轴心点。
    按住 Ctrl 改为前后左右移动轴心点。
左键拖拽：
    围绕轴心点旋转摄像机。
中键单击：
    重置摄像机。
Ctrl+加号 / 减号：
    平滑放大 / 缩小。
    按住 Shift 大幅加速。
Ctrl+0：
    重置缩放级别。
